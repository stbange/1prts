# Define the first command

## Why

A field commander has to run a base and direct a battle from one physical location. Gate Six tests whether a player can read a salvage economy, build an army and contest a switch room using the view from a factory gantry, an armored hatch and their crews' reports.

## What Changes

- Establish an embodied command interface, a scale and interior standard for every asset family, and a visual language for work in progress.
- Introduce two original forces fighting over water levels in the Orra Basin. Give them an economy, production buildings, infantry, crewed armor and different ways of crossing terrain and expanding a base.
- Define *Gate Six* as the first single-player mission with a rival operating by the same production and victory rules. Follow it with *Tide Window*, a naval supply mission with concurrent jobs and a timed berth reservation.
- Specify the C engine and editable Lua/content boundary, native and browser distribution, mobile touch and WebXR.
- Define unit coverage gates and executable mission acceptance criteria before implementation.

## Capabilities

### New Capabilities

- `field-command` covers the commander's viewpoint, crew orders and the information available in the field.
- `crewed-world` covers full-scale, staffed interiors and crossing between moving reference frames.
- `base-production` covers salvage income, powered construction and production, and each faction's forces.
- `gate-six` covers the rival base, military objective and outcome of the first mission.
- `tide-window` covers the resource decision, berth contention and objective of the second mission.
- `runtime-content` covers external game content, script extensions and the accompanying licenses.
- `platform-play` covers the desktop, mobile web and immersive paths into the same game.
- `game-verification` covers the unit coverage gate and automated gameplay checks.

## Impact

The open tasks cover the land battle first, ferry operations second and atmospheric and orbital missions later. All use the same first-person command, boarding and content contracts. [Game concept](../../../docs/concept.md) · [Field guide](../../../docs/field-guide.md)
