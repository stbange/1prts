# Make command controls accessible

## Why

A fixed keyboard, controller or pointer layout prevents some players from issuing the same order as the rest of the crew.

## What Changes

Remap keyboard and XR actions, disclose conflicts, offer sequential navigation and expose focused controls through speech and semantic browser buttons.

## Capabilities

### New Capabilities

- `accessible-input` covers configure and operate command controls.

## Impact

Input dispatch, saved preferences, platform narration and the browser accessibility tree.
