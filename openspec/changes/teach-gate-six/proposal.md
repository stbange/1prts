# Rehearse first field orders

## Why

Players need to see which crew accepted an order, when construction finishes and where they can board the resulting vehicle.

## What Changes

Open a repeatable Gate Six rehearsal from the desk, provide guidance from live simulation state and restore the prior watch after practice.

## Capabilities

### Modified Capabilities

- `commander-feedback` covers read a threat to the objective.

## Impact

First-person HUD, briefings and saved simulation state. The delta extends the existing commander-feedback requirement.
