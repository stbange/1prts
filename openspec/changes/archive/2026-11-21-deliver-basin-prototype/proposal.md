# Deliver the basin prototype

## Why

The campaign needs a larger roster and a playable operation where the commander can inspect a real production delay, board a vehicle and direct an outcome.

## What Changes

- Triple the campaign field-guide counts and make the catalog readable in game.
- Deliver Gate Six as the first executable operation using the C/SDL3/OpenGL host and loose Lua and art files.
- Record reproducible victories, defeats, input checks and first-person framebuffer captures.

## Capabilities

### New Capabilities

- `campaign-catalog` defines the expanded roster and theater inventory.
- `field-prototype` defines the implemented native and browser game loop, commands and visual evidence.

## Impact

The longer campaign proposal continues to describe future operations, richer crew behavior and content packs. This milestone delivers its first playable encounter.
