# Prototype design

The editable catalog assigns five distinct units to each of six factions and nine shared types. Twenty-one general facilities, six faction facilities and three objectives make up the structure list. Each operation has an ID and a premise. The guide exposes role descriptions in the commander's view.

The introductory encounter uses a small force from the larger theater roster. Lua owns campaign data, queue costs, AI orders, haul cycles and the result. C polls SDL3, advances the 30 Hz rules, resolves walking and vehicle-local boarding, and renders authored meshes and crew sprites with OpenGL. The desktop distribution resolves content beside the binary. Emscripten fetches the same files from sibling directories.

The native renderer records its framebuffer after ordinary keyboard and mouse inputs. Game replays use those same inputs. Unit coverage is collected in a fresh directory before the game replays run. WebGL smoke tests use real browser input and a simulated XR session with two views.
