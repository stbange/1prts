# Load translated interface content

## Why

A content pack can change a crew or replace a model. It should also be possible to change the words and glyphs the commander reads.

## What Changes

Load UTF-8 player text, numbered substitutions and optional glyphs from loose files. Support pack-declared locales and independent English fallback.

## Capabilities

### New Capabilities

- `localized-content` covers load localized player-facing text and fonts.

## Impact

Locale manifests, text rendering and the Wire Quay example pack.
